8/8 have a VISIBLE terminal goal. None is a pure goal-unobservable (W1) wall like ls20's invisible rotation. The campaign conflated "goal unobservable" with "mechanic hard to discover + planning hard." The terminal-goal vocabulary is compact — 3 archetypes (reach-cell, pattern-match-into-slots, fill-region) cover all 8 — so goal-binding is easy. The real wall is a hidden, mostly-bespoke GATING MECHANIC + multi-step planning under a tight step budget.
Why this is more optimistic: mechanic-discovery is a dense-signal problem — every action visibly changes the frame (a block moves, a ghost spawns, a tile recolors) — unlike true W1 goal-polarity aliasing (REACH≡AVOID, no pre-reward signal). We already have a forward model at 93–100% next-frame accuracy. So the wall is hard planning, not information-theoretic impossibility. Convex-hull-closed (synthetic polarity inference) does not apply — these goals don't need inferring.
Honest caveats: 3 games have deeply hidden/indirect mechanics — g50t (self-referential clone-recorder), sc25 (exact 3×3 glyph then cast), sb26 L1+ (recursive color-pointer) — which generic discovery is very unlikely to crack without game-specific priors (overfitting). And prior manual RE was wrong on several (wa30 ≠ slide-until-wall; re86 ≠ cursor→crosshair; dc22 is normal-winnable), so treat all mechanic reads as hypotheses to verify in-engine.

Combined verdict & revised bet

Two evidence-grounded levers (both additive, both keep the 0.33 floor)

Lever A — deep-level efficiency validated real: a ~10× per-level RHAE multiplier that only shows on deep levels (L1+) = private prize games. Already shipped (geodesic v23); Exp 1 confirms the mechanism and quantifies it. Public-inert by nature (public is shallow) — its payoff is the hidden private set.

Lever B — visible-goal-conditioned planner + online mechanic discovery revised bet, needs build+test: bind the salient visible goal (easy — Exp 2), learn local dynamics by interaction (dense signal; forward model exists ~95%), and PLAN a bounded action sequence to the goal under the step budget. Run as an additive, stall-gated portfolio play (never reorders coverage = avoids the W3/GraphRanker kill). This supersedes the frozen "goal-prior library" (CGPP) — Exp 2 shows goal-binding isn't the bottleneck, so a goal library adds little; planning-to-a-visible-goal is the real work.

Target the ~4 tractable games (dc22, bp35, ka59, wa30 = reach-visible-goal + learnable mechanic + moderate planning). Treat g50t/sc25/sb26-L1+ as likely-out-of-reach without overfit priors. This revives the forward-model+planner line the campaign killed as "+0 because bottleneck is goal location" — Exp 2 proves the bottleneck is NOT goal location.

Net belief update: the true W1 wall (goal genuinely unobservable) is real for only a narrow class (invisible-state like ls20 — which our explorer already solves — plus 1-bit goal-polarity, resolvable by one touch). The zero-games are gated by planning + mechanic-discovery, which is hard but attackable with dense signal. This is a materially better-grounded and more optimistic position than "offline caps at 0.33 because of W1."
