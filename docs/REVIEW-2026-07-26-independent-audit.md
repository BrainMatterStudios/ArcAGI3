## 6. Strategy verdict

**Both judges: the plan SURVIVES** — the four-gate architecture (serve-verify → A1 sweep → doctrine A/B → gated debut) is conceptually sound, but two gates are **broken as built** and must not run until the §3 fixes land. Judge consensus on the failure mode: as written, serve-verify v2 is a guaranteed false negative (KeyError) and the debut assert either crashes the scored slot or silently ships base — the 1.26 failure again.

**Single highest-EV course correction (both judges converge):** **stop using the public leaderboard as a measurement instrument.** Final standing ≈ max of 2 frozen private draws on a game set nobody has seen scored. Move all selection to paired local holdout A/Bs; spend daily slots only on gate-passed debuts and end-game banking; **select the final 2 as duplicate submissions of the single best-evidenced config** (max of 2 independent private draws ≈ true mean + ~0.10), not the best-2 public scores (1.26+1.14 expected private value ≈ 0.91-0.98). Secondary re-ranking: the completed-share cap makes level-depth strictly dominant — SFT capability first, death-avoidance second, efficiency third; add post-WIN replay to the wk2/3 bundle (with ledger preservation across the win-reset, since the run_complete wipe would erase the solution exactly when replay starts).

**Solve-all ceiling, honestly:** astroseger EWM (~99%) and "Schema" run on GPT-5.6/Opus-class frontier brains. No verified path runs them offline in 96GB; local-brain EWM was empirically killed (12 clean runs, 0 levels). Solving all games by Nov is **not a realistic target**; winning on true mean is.

**Brain landscape:** claim holds amended — no open-weight model decisively stronger than Qwen3.6-27B fits 96GB (GLM-5.2/K2.5/K3/DeepSeek-V4/MiniMax-M3 all 1.5-15x over). Mistral Medium 3.5 fits at Q4 but is a ~4.7x per-token compute loss under the 9h cap; Qwen3-Coder-Next is faster but weaker-reasoning. Stay on the duck's base.
