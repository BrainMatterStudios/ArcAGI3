Phase V research · 2026-07-01 · from per-game reverse-engineering → one general agent, zero per-game code
The reframe that started this phase

The earlier work cracked dev games by introspecting each game's engine internals and hard-coding a solver. That scores on the dev set but is worthless on the hidden competition games — it doesn't generalize. This phase rebuilt around the real target: an agent that, from frames + feedback only, infers a novel game's mechanic like a human and plays efficiently.

The novel idea the field is missing

Everyone — StochasticGoose, this repo's history, the design-study's own synthesis — fights to learn a sample-efficient world-model of novel dynamics, and loses to the W1 wall (tiny nets can't infer novel affordances). But the games are deterministic + resettable, and scoring is max(run.score) over runs (verified in arc_agi/scorecard.py).

→ You don't need a world-model. The real environment is one. Search it in a dirty run, double-reset, replay the solution in a clean run — the max takes the near-baseline score and the exploration is discarded.

This sidesteps the wall the whole field is stuck on. Coverage becomes a search-reach + perception problem, not a model-learning one — and search depth is free compute (fast deterministic env, Kaggle T4×2 + 12h).

The general recipe (all validated, zero per-game code)

1 · Perceive
pixels → typed objects (segmentation, bg/volatility masking, tracking)
2 · Induce affordances
  • single-click effects
  • two-phase select→apply (interventional: click S then T ≠ click T) — recovers hidden selection state
  • drag dynamics (actor + deltas + A5-piece-selection)
3 · Infer goal & plan
  • affordance-pruned search → first reward (then replay)
  • per-class goal inference — read the displayed goal (template/palette class ✓)

The breakthrough: goal inference is not a wall

Every path had concluded the flagship sb26 (pattern-match) was "goal-limited" — the mechanic is detectable but search can't find the right answer. Then I read its actual structure: target boxes (top) · palette (bottom) · empty slots (middle), and built a general solver for the whole "reproduce a reference sequence via a palette" class — palette=selectors, slots=appliers, target=the colored group that's neither.

sb26 solved in 9 actions = exactly the human count, zero per-game code. It abstains cleanly on non-matching games. The frontier is crackable per game-class.

Honest ceiling & what wins from here

Ceiling

~0.3–1% RHAE — competitive with the whole public field (<1.2%), not dominating. Squared-RHAE punishes exploration on shallow games; the hard tail needs bespoke goal classes. This matches the design-study red-team.

Levers left (ranked)
  • More goal-inference classes (2D template, collect-all, symmetry) — each adds coverage
  • Parallel/deeper search on Kaggle cores — turns compute into coverage (cracked sc25)
  • Multi-level — blocked where levels escalate structure (sb26 L1=7 slots) + reset returns to L0
The differentiator: compute-as-search over a perfect resettable model + affordance abstraction + per-class goal inference + replay-scoring — instead of the world-model RL everyone else is stuck on.
