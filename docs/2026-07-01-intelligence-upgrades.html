Making the agent more intelligent on HIDDEN games

Research roadmap · 2026-07-01 · self-authored (the multi-agent workflow hit the weekly limit; resets Jul 3)
The problem, precisely. The current agent solves 25/25 dev games and the deployed general agent solves ~11/25 reactively zero-code. But HIDDEN games have new mechanics/palettes/layouts. The honest question: which upgrades most raise the probability of solving a game we have never seen? Ranked by (generalization × buildability × floor-safety), grounded in the agent's real weaknesses.

Ranked upgrades

1Color-agnostic ROLE induction  do first · cheap · floor-safe

Weakness it fixes: centroid-drag keys on colors 6/15/3, pull-drag on 9/15 — brittle on hidden palettes. Replace color constants with BEHAVIOUR/STRUCTURE: avatar/mover = the object that translates under actions (probe); goal = the salient distinct static object, or the one whose change precedes reward; selector/applier/handle = identified by their PROBED effect (the template class already does this — it is the model to copy). Every class then fires on hidden colors/layouts.

First experiment (cheap): recolor a dev class-game (permute its palette) and confirm the class still detects+solves; leave-COLOR-out. If a class only works on the original palette, it is not general — fix it. Highest-probability win: it makes the classes we already have transfer.

2General GOAL inference via counterfactual credit assignment  high value

Weakness it fixes: goal inference only exists for the template class. The env is deterministic + resettable, so once ANY reward is reached (even by search/luck) we can do PERFECT credit assignment: delete-and-replay to find the CRITICAL actions (ddmin, already built in minimize_solution.py), and diff the pre-reward frames to find WHICH object/feature change caused the reward -> learn a transferable goal PREDICATE. It transfers across levels (level-weighted RHAE) and generalizes goal inference to any game where one reward is reachable.

First experiment: on dev games solved by search, extract the learned predicate from the win transition and verify it re-solves L1+ without re-search.

3Richer EFFECT induction (mechanic vocabulary)  medium-high

Weakness it fixes: affordance induction covers move/click/select/drag but not the mechanics that fooled us on dev games. A general effect-classifier names each action/interaction effect from a few probes: TRANSLATE / ROTATE (A5 orientation) / PAINT (trail) / COLLECT (vanish-on-contact) / TOGGLE / SELECT / LAUNCH (bump imparts momentum — ka59) / GRAVITY (auto-fall + sign — bp35) / CLONE-RECORD (A5 banks a replaying ghost — g50t). Each new effect + a planner hook expands the space of hidden mechanics we can model.

First experiment: add a rotate + gravity-sign + launch detector; verify on the dev games that used them (ka59/bp35) via probing, then leave-mechanics-out on a held-out.

4Self-growing CLASS LIBRARY + structural matcher  medium

Formalize every class as a (behavioural-signature, parameterized-solver) pair; a matcher classifies a hidden game to the nearest class by signature (not colors) and, crucially, handles a game that is a COMPOSITION of known classes. Makes the library extensible and turns "add a class" into data, not code.

5Smarter / deeper SEARCH  wall-time-bounded

A*/greedy with a general progress heuristic (frame-completion / distance-to-salient-goal), hierarchical macro-abstraction, iterative deepening. CAVEAT (honest): the search cost is discarded in SCORE (max-over-runs replay) but NOT in WALL-TIME — every search action is a live REST call at eval, so per-game deep search is bounded by the 12h budget, not by score. Parallelism helps ACROSS games (swarm), not within a single deep game. Lower ROI than 1–3.

6Local NEURAL reasoner  high ceiling · high risk

A small LOCAL model (fits T4, offline) that hypothesizes the mechanic/goal in structured form when symbolic induction fails — the only path for a TRULY novel affordance (the W1 gap). Risks: which model fits T4 offline; latency vs 12h/1-submission; and it MUST be grounded/verified against the deterministic env so it never ships a hallucinated plan (propose plan -> replay-verify -> only then commit). Highest ceiling, but do it last and gated.

HONEST CEILING: these raise the FRACTION of hidden games whose mechanic is expressible/inducible — but a game whose win condition is genuinely outside the affordance+class+reasoner span still scores ~0 (and abstains, floor-safe). The field is <1.2% RHAE; the realistic target is competitive coverage of the inducible slice + human-level efficiency on it (replay), not domination. Key proven lesson: every "impossible" dev game fell to deeper mechanic decode — so the ceiling is decode/perception depth, not a hard wall.
Recommended: build #1 (color-agnostic roles) next. Cheapest, floor-safe, and it directly converts the classes we already have from dev-specific into hidden-game-general — the single highest-probability improvement per unit effort.
