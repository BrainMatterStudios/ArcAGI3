## 0. The claim

**v8's run envelope is a strict subset of v7's flown envelope.** v7 flew the
scored box at 1.51 with a 45-minute cumulative grind cap, 600 s/1500 s
per-engagement caps, a run-wide semaphore of 1 and an 18000 s start cutoff.
v8 keeps every one of those knobs at its v7 default, adds two guards v7 did
not have, converts entry-time polling into per-action enforcement, and caps
every new mechanism explicitly. No knob is loosened.

The 08-20 precedent (sub 55634118, killed at the 9 h wall) was an
**unbounded** grinder. The v2 arm completed the envelope with unbounded 20-min
grinds; 2700 s cumulative is inside empirically-proven-safe territory.

## 1. The box

| quantity | value | source |
|---|---|---|
| scored games | 110 | run geometry |
| worker concurrency | 28 | run geometry |
| waves | `ceil(110/28)` = 4 | arithmetic |
| nominal per-game slot | 7920 s | run geometry |
| nominal run wall | `4 x 7920` = 31680 s = 8.80 h | arithmetic |
| hard box | 32400 s = 9.00 h | Kaggle |
| nominal slack | 720 s | 32400 − 31680 |

The nominal 720 s slack is *not* what funds grinding. Grinding is funded by
**early finishes**: a game that completes before its slot expires returns its
worker, and the grinder only ever engages games that have already stalled
(v7 trigger: ≥120 scored actions or ≥10 LLM turns on one level with zero
completions this run). A stalled game is by construction not going to use its
remaining slot productively.

## 3. New mechanisms — every one capped

| mechanism | cost, measured | cap | can it extend the run? |
|---|---|---|---|
| warmup + mask freeze | 40–111 engine actions across all 25 fixtures | inside guards #2–#5; soft cap `EXPLORER_V8_WARMUP_ACTIONS` = 600 (logged if overrun) | no |
| **specialist detection** (frame-only, 4 detectors) | 4–114 actions; **worst case any fixture = 206 actions warmup+detect = 1.6 s at 130 act/s**, mean 123 actions = 0.95 s | inside guards #2–#5 | no |
| specialist solve (when it fires) | ft09: 1144 actions for all 6 levels = **8.8 s live** | lane slice, then closes permanently on one failure | no |
| Rollout-IW / nbfs / macros / Go-Explore lanes | see §4 | lane slice ≤ `remaining_s()`; guard #2–#5 per action | no |
| **bank replay** (the one thing that runs on the raw env) | ft09 75 actions = 0.6 s; tu93 187 actions = 1.4 s | hard cap `EXPLORER_V8_BANK_MAX_ACTIONS` = **2000 actions ≈ 15.4 s**; pre-checked against `remaining_s()` at a **4x-pessimistic 0.03 s/action + 10 s margin** (needs ≥70 s of remaining envelope to start); its wall is inside v7's `_GRIND_WALL_SPENT` accounting | no — it cannot start unless ≥70 s remain and it costs ≤15.4 s |

Specialist detection is *not* a per-game tax on all 110 games: it runs inside
an engagement, which is inside the semaphore and inside the 2700 s cumulative
budget. Worst case it consumes 1.6 s **of the 2700 s**, not 110 × 1.6 s.

## 4. Live-cost simulation — the two measured cracks

Method: run the v8 graft end-to-end against the offline engine on the
**reset-replay backend** (the live cost model: one reset per rollout, replay
to depth for expansion), count *every* engine call the graft makes, and price
it at the measured live gateway rate of **130 actions/second** (v7 postmortem,
one shared server at concurrency 28).

Reproduce: `ONLY_RESET_LEVELS=true .venv/bin/python -m pytest -q -s
submission/_explorer_v8/test_graft_explorer_v8.py -k test_H`

| game | levels | lane | engine actions | live wall @130 act/s | first unlock | vs 600 s generic cap | vs 1500 s owned cap | bank plan |
|---|---|---|---|---|---|---|---|---|
| ft09 | 6 (**FULL CRACK**) | `spec:ft09_gf2` | 1 233 | **9.5 s** | 289 acts = 2.2 s | FITS | FITS | 75 acts = 0.6 s → **banked** |
| tu93 | 9 (**FULL CRACK**) | `nbfs_macros` | 84 687 | **651.4 s** | 3 571 acts = 27.5 s | over (n/a) | **FITS** (43 %) | 187 acts = 1.4 s → **banked** |

Cap ordering matters for tu93: the 600 s generic cap governs only until the
first grinder unlock makes the game grind-owned. tu93 reaches its first unlock
at **27.5 s live**, far inside 600 s; from there the 1500 s owned cap applies
and the full 651.4 s crack fits with 57 % headroom.

Both cracks together = **660.9 s = 24 % of the 2700 s cumulative run budget**,
i.e. the run can afford ~4 tu93-class cracks or ~280 ft09-class cracks.

Comparison with the lane being replaced, stated precisely: v7's blind BFS
**never cracked a game in any measurement** (that is why its banking path
never fired), and v7's own docstring records tu93's measured full win at
~3300 s of grind. On ft09 the closest like-for-like generic number is the
stage-2 SearchCore screening baseline of **1 level** at 120 s/game
(`run_falsifier.STAGE2_120`); the specialist lane reaches 6 levels and the
full crack in 1233 engine actions.

## 5. Does the 9 h box still close?

Worst case, in full:

```
grind wall added to the run          <= 2700 s + 0.25 s        (guard #5)
                                     serialized by the semaphore (guard #1)
last grind action                    <= 19500 s = 5.42 h        (guard #7)
remaining wall after last grind      >= 32400 - 19500 = 12900 s = 3.58 h
per-game delay from grinding         <= 1500 s of that game's 7920 s slot
                                     and only on a game already stalled
grind blocked when the game's own
soft time is under 120 s / aborted
under 60 s                                                      (guard #10)
```

Two independent reasons the box closes:

1. **Subset argument (primary).** v7 flew this exact envelope live and
   completed the run (draw 1.51). v8 does not loosen a single knob; it tightens
   guard #5 from a 4200 s worst case to 2700 s and turns guard #7 from implicit
   to enforced. If v7's envelope closed, v8's does.
2. **Arithmetic argument.** 2700 s of serialized grind against 720 s of nominal
   slack requires ~1980 s of early-finish slack across a 4-wave, 110-game run
   — 18 s per game, or equivalently 2.4 % of one wave. Grinding only engages
   stalled games, whose slots are otherwise spent on unproductive LLM turns.

**Explicit residual risk.** The arithmetic argument depends on early-finish
slack we have not re-measured this session; the subset argument does not. If a
smoke shows wall pressure, the single knob to turn is
`EXPLORER_RUN_GRIND_BUDGET_S` (2700 → 1200), which costs at most one
tu93-class crack and nothing on the ft09 class.

## 7. Fail-open inventory

| seam | failure | behaviour |
|---|---|---|
| `install()` | SearchCore/specialists unimportable, or an expected symbol missing | declines the swap, **v7 grind stays** (`test_G_install_declines_*`) |
| `_grind_v8` | no engine wrapper on the game | marks the level exhausted, returns |
| `_grind_v8` | SearchCore import fails at engagement time | falls back to `v7._grind_v7` (the blind BFS) |
| warmup | any exception | continues with the raw (unvalidated) mask |
| specialist detect | any exception | `specialist=None`, generic lanes run |
| specialist solve | any exception | `solved=False`, lane closes, generic lanes run |
| any lane | any exception | caught at `_grind_v8`, engagement ends, env RESET for the LLM |
| guard probe (`stop_event`, `runtime_limit_reached`, …) | probe itself raises | ignored; the cheap caps still bind (`test_G_guard_probe_failures_do_not_block`) |
| bank plan | does not cover level 1 onward (v7 bounded-takeover case) | declines: a fresh-play replay could not reproduce the win |
| bank replay | engine refuses / replay dies / exception | returns `(False, reason)`; the recorded win still owns the card max |
| bank replay | post-WIN RESET does not open a fresh play | trips `graft_bank._BankingKillSwitch` — banking disabled run-wide for **both** grafts |
| swallowed `_GrindAbort` | `specialists.*` catch-all eats a guard trip | re-asserted by `genv.check()` after every lane (`test_G_swallowed_abort_*`) |

## 8. v7 bug found and repaired while building this

`submission/_explorer_floor/graft_explorer.py:788` called
`bank_replay(level_seqs, int(resp.win_levels or 0) or (base_levels + 1))` —
**two arguments to a one-parameter function**, and `level_seqs` is a `dict`
whose iteration yields `int` keys. Every v7 win would have raised `TypeError`
inside `should_stop`'s blanket `except`, so the win would never have been
banked. Never observed live because v7 never cracked a game. Repaired
(dict-typed, replayed in level order) and covered by
`test_F_v7_bank_replay_arity_repaired`.

## 9. Bundle layout

The graft resolves its dependencies through `_candidate_dirs()`: an
`EXPLORER_V8_CORE_DIR` override first, then its own directory, then the dev
tree's `_search_core` / `_explorer_floor` / `_duck38_v12_bank` siblings.
A Kaggle bundle therefore only needs the five files flat in one directory:

```
graft_explorer_v8.py   search_core.py   specialists.py
graft_explorer.py      graft_bank.py
```

Verified 2026-08-26 by copying exactly those five files into an empty
directory and running the ft09 engagement end-to-end from it: 6 levels, full
crack, 1233 engine actions, banked in 75 actions — identical to the dev-tree
run. Runtime deps beyond the eval image: `numpy` only.
