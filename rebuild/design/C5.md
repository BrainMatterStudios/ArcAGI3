# C5 — Goal inference

**Confidence:** 0.82

## Summary
All three proposals correctly diagnose the root cause and converge on the same structural fix: never diff the post-reward frame (it is the rebuilt next level), instead capture the board the rewarding action acted on (self.prev_grid, which the policy must newly retain) and reconstruct the rewarding event from it. The synthesized blueprint takes Proposal 3's passive observer + board-swap guard + fallback event derivation (the safest, most self-contained), Proposal 2's role->color->shape three-tier signature and Laplace-smoothed confirm/contradict evidence (the strongest generality lever), and Proposal 1's tight, minimal interface and explicit reuse of the lru_cached connected_components (cheapest). Critically, C5 ships in two strictly separated milestones: M1 is pure observation (zero action-path changes -> regression structurally impossible, satisfies the plan's 'neutral for foundations' clause), and any targeting bias is deferred and gated behind its own A/B per the measurement protocol. The plan is explicit that identification was ALREADY shown correct on m0r0 yet did not move levels -- the real bottleneck is achievement (C6). So C5's true deliverable is a reliable typed GoalHypothesis that C6 consumes, NOT an in-policy bias; the bias is an optional, separately-gated experiment that must not be the thing C5 is judged on.

## Data structures
Per-game (persistent across levels, reset in policy.reset_all): GoalModel{ hyps: dict[(kind,color,aux)->GoalHypothesis], levelups_seen:int }. GoalHypothesis carries support/contra (Laplace confidence) + three-tier signature (role->color->shape_sig). Per-level (cleared on level-up / on_level_start): _buf: collections.deque[StepRecord] maxlen K=4 (the masking fix -- holds pre-swap transitions); _level_census: dict[int->int] color->cellcount snapshot at level start (enables 'were several, now zero' VANISH_ALL test and PUSH_TO target-cell lookup). Event/StepRecord are cheap frozen/lightweight dataclasses. Reuses existing perception.connected_components (lru_cached on grid bytes), movement.infer_all_translations, MotionModel.avatar_colors/avatar_centroid, perception.detect_background -- no new perception primitives.

SYNTHESIZED ALGORITHM:

Module src/arcagi3/goals.py (new), pure CPU, no policy import.

State (one GoalInference per game, lives on policy, survives levels, reset per game):
  _buf: deque[StepRecord] maxlen K=4 (per-level ring; cleared on level-up/level-start)
  model: GoalModel (persistent across levels)
  _level_census: dict[color->cellcount] snapshot at level start (for "were several, now zero")
  _level: int

observe_step(prev_grid, cur_grid, prev_action, reward, bg, distractor_colors, avatar, events=None):
  1. Guards: if prev_grid is None or prev_action is None or just-consumed-reset -> remember & return (never attribute across reset; mirrors policy.expect_reset null of prev_action).
  2. swap = _is_board_swap(prev_grid, cur_grid, bg):
       True if prev.shape!=cur.shape, OR changed_cells >= 0.6*size, OR changed_cells >= 1.5*nonbg_cells, OR detect_background(prev)!=detect_background(cur).
  3. events for THIS transition:
       if events is not None (C2 wired later): ev = tuple(events)
       elif swap: ev = ()   # NEVER diff across a swap -- this is the whole fix
       else: ev = _derive_events(prev_grid, cur_grid, bg, distractor_colors, avatar)
  4. rec = StepRecord(action=prev_action, events=ev, avatar_xy=..., moved=...)
  5. if reward > 0:
        _credit_levelup(reward)   # reads buffered PRE-swap records, not this swap frame
        _buf.clear()
     else:
        _buf.append(rec)

_derive_events(prev, cur, bg, distractors, avatar)  [the C2-less fallback]:
  ignore = distractors | avatar.avatar_colors | {bg}   # avatar-footprint subtraction = the proven masking fix
  trans = infer_all_translations(prev, cur, bg)
  for each non-ignored color c that changed (prev==c vs cur==c not equal):
    if c in trans and trans[c]!=(0,0): EV_MOVE_OBJ(c)   # push/sokoban mover
    elif count went >0 -> 0: EV_VANISH(c)
    elif 0 -> >0: EV_APPEAR(c)
    elif count decreased: EV_COUNT_DN(c)
    elif count increased: EV_COUNT_UP(c)
    else (same count, cells differ, no translation): EV_RECOLOR(c)   # door/switch toggle
  if avatar.ok: EV_AVATAR_ON(color under avatar centroid on cur, if non-ignored)

_credit_levelup(reward):
  model.levelups_seen += 1
  rec = most-recent buffered record with non-empty events (the pre-swap rewarding step)
  cands = _hyps_from_record(rec) + _reach_hyps_from_buf()
  Build each candidate with a THREE-TIER signature (from P2): target_role (None until C3),
    target_color (primary key now), target_shape_sig=(h,w,size) (color-invariant fallback).
  Event->hypothesis map:
    EV_VANISH(c) or EV_COUNT_DN(c)->0, AND census[c] had >=1 at level start -> VANISH_ALL(c)
    EV_MOVE_OBJ(c) landing on cell that held color aux at level start -> PUSH_TO(color=c, aux=aux)
    EV_AVATAR_ON(c) on the rewarding step -> REACH(c)
    EV_RECOLOR(c) -> RECOLOR_ALL(c)  (and if an earlier buffered EV_RECOLOR precedes a REACH,
       record it as a secondary lower-support TOGGLE_THEN_REACH precondition -- from P2)
    click action token ("C",x,y): look up grid[y,x] on rec board (CONVENTION: token is x=col,y=row,
       mapped {"x":a[1],"y":a[2]} per agent.py:44) -> CLICK_TARGET(color)
  For each cand key (kind,color,aux): if exists -> support+=1 else insert support=1.
  Contradiction: for each existing hyp NOT in this level's cands whose precondition WAS applicable
    (its target color/role present at this level start) -> contra+=1.  (fair penalty only)
  prune hyps with confidence<0.3 after >=2 levelups and support 0.

confidence = (support+1)/(support+contra+2)  [Laplace, from P2]; best(min_conf=0.6) returns
  argmax (confidence, support) above gate, else None. Level-1 single confirm -> conf=2/3<0.6
  if we set gate 0.6+require support>=2 OR raise gate; tune so a single noisy levelup cannot
  drive action (it can't anyway in M1 -- observation only).

PUBLIC API consumed by C6/C7 only:
  current_goal() -> GoalHypothesis | None   (= model.best())
  goal_target_cells(grid) -> list[(r,c)]    (instantiate best hyp on CURRENT board:
     VANISH_ALL/REACH -> matching-color object centroids; PUSH_TO -> (block,target) pair;
     CLICK_TARGET -> matching centroids). Matching uses color first, shape_sig fallback.

MILESTONE SPLIT (mandatory):
  M1 (this component): observe_step + current_goal/goal_target_cells exist; _choose UNCHANGED.
     Acceptance = neutral (no action changes) + inferred goal kind == ground truth on dev games.
  M2 (DEFERRED, separate gate): optional in-policy bias in _next_target / click ordering,
     behind use_goal_bias flag, reordering-only. NOT part of C5 sign-off; the plan says

## No-regression strategy
1. MILESTONE 1 = pure observation. The ONLY action-relevant edits are: one new field (_prev_grid), one observe_step() call, one on_level_start() call, and a flag. _choose, _next_target, _nav_step, the probe state machine, and the graph fallback are byte-for-byte identical -- verify with `git diff src/arcagi3/policy.py` showing no change inside _choose. Because action selection is provably unchanged, local 8/8 (27/27) + push 3/3 CANNOT regress by construction. This is the safest possible landing and matches the plan's 'neutral for foundations' acceptance clause.

2. Feature flag + env override (infer_goals=True default, ARCAGI3_GOAL_INFER=0). If any measurement shows a perf/budget leak, flip off without reverting code. Flag wraps construction AND the observe_step call so the path is fully dead when off.

3. Hard performance budget. observe_step is O(#colors + #objects); reuses lru_cached connected_components and infer_all_translations (same args the policy already calls -> pure cache hits). Add a microbench test asserting observe_step < ~0.3ms on a 64x64 frame so it never eats the actions/sec budget that RESULTS.md identifies as the dominant lever.

4. Reset/boundary safety. Skip observe_step when self.expect_reset was just consumed (mirrors policy nulling prev_action across reset) so reward is never mis-attributed across a death/reset. _buf cleared on level-up and on_level_start; model persists across levels (the refinement requirement) but resets per game in reset_all.

5. Board-swap guard is conservative: on a detected swap we emit ZERO events (learn nothing this step), never WRONG events. The true rewarding events come from the buffered pre-swap record. Worst case under a mis-tuned threshold is a missed lesson, not a corrupted hypothesis.

6. Determinism. All tie-breaks sorted by (confidence, support) then stable key -> 8/8 suite stays reproducible; existing seed plumbing untouched.

7. M2 (in-policy targeting bias) is explicitly OUT of the C5 sign-off and gated SEPARATELY: behind use_goal_bias=False, reordering-only (never excludes candidates, never disables graph fallback -> the push solver is structurally protected), and promoted only via the A/B protocol on {tu93,ls20,m0r0,su15,vc33,re86,wa30} with zero per-game regression. Given the plan's finding that identification already worked on m0r0 without moving levels, M2 is low-priority; the durable deliverable is current_goal() for C6.

8. Regression-canary tests: tests/test_goals.py drives HybridPolicy through the offline env on navg/maze/collect/push/switchdoor and asserts inferred current_goal().kind == ground-truth mechanic (REACH/REACH/VANISH_ALL/PUSH_TO/RECOLOR_ALL). Plus isolated unit tests on hand-built 8x8 arrays for _is_board_swap and each event type. Existing tests/test_agent.py is left untouched.

## Risks
R1 (highest) -- Misjudging C5's purpose: the plan states identification was ALREADY correct on m0r0 yet levels did not move; achievement (C6) is the bottleneck. If C5 is judged on in-policy level gains it will look like a failure. Mitigation: judge M1 on neutrality + inference-correctness (kind matches ground truth), and treat current_goal() for C6 as the real deliverable; defer/de-prioritize the bias. R2 -- Board-swap threshold mis-tuned for a game that legitimately repaints >60% within a level: conservative-by-design (emit no events on swap -> miss a lesson, never corrupt). R3 -- Avatar mis-identified or mm None -> avatar motion credited as a game event: subtract distractor_colors even when mm is None; down-weight EV_MOVE_OBJ; spurious hyp only matters once C6 acts (separately gated). R4 -- Click convention bug (x=col,y=row): pinned to agent.py:44 mapping, covered by a unit test. R5 -- collect single-step (discard item + next_level in the SAME action): the rewarding board is prev_grid (pre-swap), captured correctly; census 'were several, now zero' must read the LEVEL-START census, not the last buffered record (the last item is gone from cur but present in prev_grid). R6 -- _new_level signature change to accept grid: low-risk, both call sites (107, 131) have grid in scope -- verified. R7 -- Performance leak eating actions/sec: microbench gate + cache-hit reuse. R8 -- P2-style dependence on unbuilt C1/C2/C3: avoided by making events an optional param defaulting to the self-contained _derive_events fallback, so C5 lands and is testable before C2/C3 exist.
