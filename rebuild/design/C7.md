## Summary
WorldModelPolicy is a thin orchestrator that COMPOSES (does not subclass or edit) a proven HybridPolicy instance and only ever intercepts control to execute a confident, divergence-monitored plan; otherwise it returns byte-for-byte what HybridPolicy.decide would have returned. The keystone safety property (verified by a lockstep identity test, not by hope) is: with planning off or unconfident, WorldModelPolicy.decide(...) == HybridPolicy.decide(...) token-for-token on all 8 local games. The single hardest correctness issue, which Proposals 2 and 3 both correctly diagnose against the real code (policy.py:115-136), is bookkeeping consistency: HybridPolicy records self.prev_action as the token it RETURNED, so if the wrapper injects a different (planned) action the inner policy's WorldModel/motion votes silently corrupt and the fallback we depend on degrades. The synthesis solves this with Proposal 3's minimal, zero-edit-to-HybridPolicy approach: always call inner.decide() first every step (keeps graph/motion/distractor state fully warm), then if we override with a plan action, write the actually-executed token back into inner.prev_action — a single corrective assignment, no control-flow change, no refactor of the proven method. Generality comes from ADDING goal-directed planning over object-level abstractions (reusing the already-tested spatial.OccupancyMap/A*, MotionModel, object_state_key, and the hard-won distractor_colors masking) that fires only when verified, never from removing the breadth that already wins 8 archetypes. All C1–C6 components are consumed through optional duck-typed handles so C7 lands and passes the gate with ZERO planning components present (degenerate == HybridPolicy), surviving partial reverts of upstream components. Defense-in-depth no-regression: default-off selector, composition (policy.py untouched), lockstep identity test, sticky per-level circuit breaker, per-step divergence guard mirroring GraphStrategy._expect, shadow-mode-first on the fragile push archetype, and exception containment that degrades to the proven policy rather than crashing.

## Algorithm
CORE DECISION (WorldModelPolicy.decide), one action per call, matching HybridPolicy.decide signature:

decide(grid, terminal, notplayed, levels, available):
  # (A) ALWAYS advance the proven policy first — keeps graph edges, probe votes,
  #     motion model, distractor detection perfectly warm (policy.py:114-127).
  base_token = self.base.decide(grid, terminal, notplayed, levels, available)
  out = base_token

  # (B) Hard passthroughs: kill-switch / terminal / notplayed / reset -> exactly base.
  if (not self.cfg.enabled) or terminal or notplayed or base_token[0] == 'reset':
      self._on_reset_or_terminal(levels)
      return base_token

  # (C) Level change -> reset per-level WM state (KEEP affordances+goal across levels).
  if levels != self.s.level:
      self._new_level(levels)
  self.s.actions_this_level += 1

  # (D) Observe transition INTO this frame using base.prev_key/base.prev_action as the
  #     cause (set by step (A)); feeds C1/C2/C3/C5. Wrapped in try/except (D6).
  try: self._observe(grid, levels, available)
  except Exception: self._disable_level(self.s.level); return base_token

  # (E) Sticky disable (circuit breaker) -> pure passthrough rest of level.
  if self.s.level in self.s.level_disabled: return base_token

  # (F) Never fight probe: while base is still learning the motion model, we have no
  #     model either -> delegate. (base.phase=='probe' or base.mm is None or not base.mm.ok)
  if self.base.phase == 'probe' or self.base.mm is None or not self.base.mm.ok:
      return base_token

  # (G) Budget floor: let proven nav have first crack each level.
  if self.s.actions_this_level < self.cfg.min_delegate_actions: return base_token

  # (H) Continue a committed, still-valid plan (EXECUTE) with divergence guard.
  if self.s.plan:
      cur_key = self.base._key(grid)            # SAME keying as base (reuse, R2 guard)
      if self.s.plan_expect_key is not None and cur_key != self.s.plan_expect_key:
          self.s.plan = []; self.s.plan_aborts += 1; self._maybe_disable_planner()
      else:
          tok = self.s.plan[0]
          if self._action_legal(tok, available):
              self.s.plan.pop(0)
              self.s.plan_expect_key = self._predict_key(grid, tok)  # C4
              out = tok
          else:
              self.s.plan = []

  # (I) No live plan: try to form one if a confident goal exists.
  if not self.s.plan and out is base_token and self._goal_ready():
      goal = self.goal.hypothesis()
      if goal and goal.conf >= self._conf_gate(goal) and self.s.plan_aborts < self.cfg.plan_fail_limit:
          occ = self._occupancy_from_base()      # spatial.OccupancyMap(base.mm.deltas)
          plan = self._replan(grid, goal, occ, available)  # C6 over C4
          if plan and self.cfg.min_plan_len <= len(plan) <= self.cfg.max_plan_len and self._shadow_ok(goal):
              self.s.plan = list(plan); self.s.plan_goal_sig = goal.signature()
              tok = self.s.plan[0]
              if self._action_legal(tok, available):
                  self.s.plan.pop(0); self.s.plan_expect_key = self._predict_key(grid, tok); out = tok
          else:
              self._maybe_disable_planner()

  # (J) THE CRUX: if we are overriding, correct the inner policy's record so its next
  #     transition is computed against the action ACTUALLY executed (no lie). This is the
  #     ONLY write into base and it changes no control flow (mirrors policy.py:136).
  if out is not base_token:
      self.base.prev_action = None if out[0] == 'reset' else out
  return out

PREDICT_KEY (C4 forward model, must hash identically to base):
  for ('S',aid): translate avatar cells by base.mm.deltas[aid]; apply C3 affordance to
  contacted object colors (PUSH shifts block, COLLECT removes, TOGGLE recolors); then
  return P.object_state_key(predicted_grid, background=base.bg, ignore_colors=base.distractor_colors)
  — IDENTICAL call to HybridPolicy._key (policy.py:67) so predicted keys compare to live keys.

REPLAN (C6): build OccupancyMap from base.mm.deltas; exclude movable/affordance!=BLOCK
  colors from walls (push-safe per REBUILD_PLAN C6); BFS/A* over forward model to goal;
  return action-token list or None. Only on goal-signature change or plan invalidation (cache by plan_goal_sig).

SHADOW MODE (push guard, D3): the FIRST time the planner would take control on a level
  whose goal is PUSH-type, do NOT take control: predict the next key, return base_token,
  and on the next step compare predicted vs realized key. Grant control only after a
  shadow prediction matched reality. A wrong push model thus never silently takes over.

_maybe_disable_planner: increment miss/abort counter; if >= plan_fail_limit, add level to
  level_disabled (sticky) -> pure passthrough for the remainder of that level.
