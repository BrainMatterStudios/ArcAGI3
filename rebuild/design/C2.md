# C2 — Causal event extraction

**Confidence:** 0.83

## Summary
A read-only, default-OFF module `src/arcagi3/events.py` that, given the settled before/after grid pair around one action plus the existing MotionModel, subtracts the avatar's actual footprint (cells the avatar vacated or newly covers, by avatar_colors mask XOR/union) and classifies the geometric residual into a typed event stream (VANISH, APPEAR, OBJECT_MOVE, RECOLOR, COUNTER, AVATAR_BLOCKED, LEVEL_COMPLETED). A pure avatar move over floor/maze leaves zero residual -> empty event list -> has_real_event=False, which is the direct antidote to the "98% of states look like progress" failure. The collect mechanic is captured by promoting "avatar stepped onto a non-bg, non-avatar cell" to a contact VANISH; the switchdoor remote door is captured as a non-contact VANISH on the same step as the switch contact; push is captured as OBJECT_MOVE via the existing infer_all_translations restricted to non-avatar colors. C2 is wired into policy.py behind an `emit_events=False` flag and consults nothing in the default decision path, so local 8/8 + push 3/3 are byte-identical by construction; it never feeds the state key or distractor set. Synthesizes the cleanest ideas from all three proposals: Proposal 3's strictest no-regression discipline (flag-gated, read-only, push as first-class event, COUNTER never mutates masking) as the backbone; Proposal 2's footprint-XOR + reveal/collect-promotion + avatarless click handling + whole-frame-redraw guard for generality; Proposal 1's frozen Event schema, EventLog accumulator, and the critical "log events BEFORE the level-relearn block" robustness fix that the naive goal-inference lacked.

## Data structures
EventType (Enum), Event (frozen dataclass: type, color, cells, bbox, size, delta, action, avatar_cell, contact, local, low_confidence, extra), StepEvents (events tuple, action, reward, avatar_moved, avatar_blocked, has_real_event/salient props), EventLog (per-level accumulator with last_real(n) for C5), EventExtractor (holds background + tiny per-color change-history ring buffer for COUNTER confirmation; stateless across calls except that history). Reuses perception.Obj, perception.connected_components (memoized), movement.MotionModel.avatar_cells/avatar_centroid/deltas, movement.infer_all_translations.

## Algorithm
extract(before, after, action, reward, mm, bg, distractor_colors) -> StepEvents:

0. FAST PATHS
   - if reward > 0: emit LEVEL_COMPLETED (authoritative headline event). Continue (still extract the triggering residual on this pre-reward transition).
   - if np.array_equal(before, after): return StepEvents(events=(LEVEL_COMPLETED if reward>0 else ()), action, reward). (cheap; common for no-op clicks)

1. CHANGED MASK + REDRAW GUARD
   - diff = (before != after); n = diff.sum()
   - if n == 0: handled above.
   - if n > 0.40 * grid.size: emit single REGION_CHANGED(low_confidence=True); return. (animation/scene-transition blowup guard from Proposal 2)

2. AVATAR FOOTPRINT (only if mm and mm.ok)
   - avatar_cols = set(mm.avatar_colors) or {mm.avatar_color}
   - av_b = mm.avatar_cells(before); av_a = mm.avatar_cells(after)  (np.argwhere over avatar mask)
   - footprint = set(map(tuple,av_b)) | set(map(tuple,av_a))   # union = vacated + newly-covered
   - centroid shift: avatar_moved = ||mean(av_a)-mean(av_b)|| >= 0.5
   - if mm is None or not mm.ok: footprint=empty, avatar_moved=False (degraded: all change is residual — correct for click games / pre-probe)

3. COLLECT PROMOTION (reveal-under-footprint)
   - for each cell (r,c) the avatar NEWLY covers (in av_a, not av_b):
       under = before[r,c]
       if under != bg and under not in avatar_cols:
           collect_cells.setdefault(under, []).append((r,c))   # avatar stepped onto a real object -> it vanished
   - (vacated cells: record revealed_color for future C3 floor-learning, emit NO event — incidental)
   - emit OBJECT_VANISHED per (under-color, connected group of collect_cells) with contact=True, then remove those cells from consideration.

4. RESIDUAL = diff cells MINUS footprint cells MINUS collect cells.
   A diff cell is INCIDENTAL (dropped) iff {before[r,c], after[r,c]} subset of (avatar_cols | {bg}).
   if residual is empty (after steps 3 collect handled separately): events = (collect events + level_completed); has_real_event from those. THIS IS THE 98%-NOISE KILLER for plain navigation.

5. CLASSIFY RESIDUAL (order matters; remove cells as consumed):
   a. OBJECT_MOVE: trans = MV.infer_all_translations(before, after, bg); for color c not in avatar_cols with nonzero (dr,dc) whose cells overlap residual -> emit OBJECT_MOVE(color=c, delta=(dr,dc), cells=after-cells). Remove. (push/enemy)
   b. RECOLOR: residual cells where before!=bg AND after!=bg AND both non-avatar (color->color flip in place); group by (from,to) connected region -> emit OBJECT_RECOLORED(extra={from,to}). Remove. (switch/toggle hue change)
   c. VANISH: connected components of before (non-bg, non-avatar) whose cells are now bg and in residual -> OBJECT_VANISHED. (remote door in switchdoor, item disappearance). distractor color -> COUNTER_CHANGED instead.
   d. APPEAR: connected components of after (non-bg, non-avatar) that were bg before and in residual -> OBJECT_APPEARED. distractor color -> COUNTER_CHANGED.
   e. leftover residual -> single OBJECT_APPEARED(extra={unclassified:True}) — conservative: counts as real event (never miss a goal).

6. AVATAR_BLOCKED: if action==("S",aid) and mm.deltas.get(aid) is nonzero and not avatar_moved and no OBJECT_MOVE fired for the cell ahead -> emit AVATAR_BLOCKED(contact=True). (wall/failed-push signal for C3)

7. CONTACT/LOCAL flags: contacted_cell = round(avatar_centroid_after + expected_delta) [or click_xy for click games]; contact_radius derived from max |delta| (default ~1.5x step). For each event with cells: contact = (min Manhattan dist from cells to contacted_cell <= radius); local = (dist to avatar centroid <= radius). (switchdoor door: contact=False,local=False; collect item: contact=True)

8. has_real_event = any(e.type not in {AVATAR_BLOCKED, COUNTER_CHANGED} for e) or reward>0. Sort events by salience (LEVEL_COMPLETED, VANISH, RECOLOR, APPEAR, MOVE, COUNTER, BLOCKED). Return StepEvents.

Complexity: O(changed cells) + a couple memoized connected_components + one infer_all_translations (already used in probe). Negligible vs an env step.

## No-regression strategy
Layered guarantees, strongest first:
1. DEFAULT-OFF FLAG (from Proposal 3, the decisive choice). `emit_events=False` everywhere the submission adapter and test suite construct HybridPolicy. When off, the entire C2 block is skipped — decide() returns byte-identical action tokens. This is not "neutral by argument," it is neutral by control-flow.
2. READ-ONLY. Even when emit_events=True, nothing in the default decision path (_choose, _key, _next_target, distractor_colors, GraphStrategy) reads self.events / self.last_step_events. C2 only writes the log. The sokoban/push win depends on object_state_key distinguishing block positions and GraphStrategy's search — C2 touches NEITHER.
3. NO NEW MASKING. The historical push/sokoban regressions all came from over-aggressive color masking shrinking the state graph. C2's COUNTER detection is REPORTED as an event, never pushed into distractor_colors or ignore_colors. The existing distractor logic at policy.py:171 is the INPUT to C2, never the output. Push (BLOCK color 6, verified ∉ {avatar 14, bg}) always survives footprint subtraction as residual -> OBJECT_MOVE; there is no code path by which C2 hides a block.
4. DETERMINISM GOLDEN TEST. Capture the exact action-token sequence of the reactive policy on all 8 local games on `main`; assert byte-identical with emit_events wired in (off, and also on — must still be identical since read-only). Run for push + switchdoor specifically (the fragile pair).
5. HARD GATE: full pytest green incl. test_reactive_solves_all_local_games (8/8), test_push_makes_progress, test_explorer_baseline_still_solves_clicks, plus test_submission's push/navg/btnc wins.
6. NEW tests/test_events.py golden streams: floor-move->0 events; collect->1 VANISH contact=True; switchdoor switch-step->VANISH door contact=False local=False + same step; push->1 OBJECT_MOVE block color, avatar separated; recolor->RECOLOR with from/to; counter->COUNTER has_real_event False; blocked move->AVATAR_BLOCKED.
7. PERF MICRO-BENCH: assert extract < ~0.5ms/typical step on 64x64; confirm runner --agent reactive action totals & timing unchanged (eval is throughput-bound).
8. C2 alone is a FOUNDATION; per REBUILD_PLAN it may be A/B-neutral on the held-out real set {tu93,ls20,m0r0,su15,vc33,re86,wa30}. The real gain is claimed only when C5/C7 consume it. Revert on ANY local or held-out regression.
DISCARDED as too risky: Proposal 2's causal_state_key wired into the explorer (collapsing avatar position in the state key is exactly the class of change that has historically broken sokoban — defer entirely to C7, do not ship in C2). Proposal 1's optional inert-target deprioritization in _next_target (changes decisions — keep out of C2).

## Risks
R1 Avatar & pushed block share a color: footprint subtraction could eat the block. Mitigation: avatar_colors requires >=2 distinct action-correlated deltas (movement.py:162); a block has a single action-dependent delta, excluded. If they truly share a color, infer_all_translations still finds two disjoint rigid translations -> OBJECT_MOVE fires. Add a shared-color-push unit test.
R2 Avatar model absent/uncertain (pre-probe, click games, mm.ok False): footprint empty -> all change is residual. Mitigation: correct behavior for click games (click_xy as contact site); for avatar games set low_confidence on events while mm not ok so C5 down-weights; consumers only trust once mm.ok.
R3 Sub-frame animation inflating diffs: to_grid returns the settled sub-frame (perception.py:29), so C2 only ever sees settled grids; plus the >40% redraw guard caps blowup.
R4 Greedy same-color matching ambiguity (multi-box sokoban): OBJECT_MOVE pairing may be wrong but still correctly signals "a box moved" — enough for the event layer; precise IDs deferred to C1.
R5 Multi-color avatar with a sub-color outside avatar_colors -> spurious events. Mitigation: footprint also treats any residual region whose rigid delta equals an avatar delta as incidental.
R6 Scope creep: keep extract stateless (except COUNTER history), schema frozen; resist causal_state_key (deferred to C7) and any _next_target change.
R7 Perf on dense frames: bounded by changed-cell count + memoized CC; micro-benchmark gate.
Overarching: the largest historical risk (state-graph collapse from masking) is structurally avoided because C2 never writes the key or the distractor set and is default-OFF.
