# C3 — Affordance Model

**Confidence:** 0.86

## Summary
Synthesized blueprint: a single new module `src/arcagi3/affordance.py` housing a pure, training-free, color-keyed online accumulator (`AffordanceModel`) plus a `ContactDetector`/`observe_step` front-end that converts (before_grid, action, after_grid, reward, terminal) into per-color affordance votes over {BLOCK,PASS,PUSH,COLLECT,TOGGLE,GOAL,HARM,NONE}. It is wired into `HybridPolicy.decide` strictly as an OBSERVE-ONLY side-car in the existing outcome block (policy.py:114-127), behind an `enable_affordance` ctor flag (default True for learning, flippable False), wrapped in try/except so it can never crash or alter the action stream. No consumption hook touches `_next_target`/`_nav_step`/`GraphStrategy` in this PR — push/sokoban (solved by the fragile graph fallback, test only needs >=1 level) is therefore bit-identical by construction, enforced by a golden action-trace equality test on push and maze. Confidence uses Dirichlet posterior with majority-vote + priority tie-break so a half-learned model is provably inert. PUSH reuses `movement.infer_all_translations` verbatim. The public query API (`affordance(color)->Verdict`, `blocks`, `pushables`, `collectibles`, `harm_colors`, `goal_colors`) is the fixed contract C4/C6 consume later; the `ContactDetector` seam lets real C1/C2 replace its internals without touching the learner or any hook.

## Data structures
- Effect (str Enum): 8 labels BLOCK/PASS/PUSH/COLLECT/TOGGLE/GOAL/HARM/NONE — complete-by-construction
  closure of single-object-on-contact outcomes on a 64x64/16-color grid (P2's argument).
- ColorStat: per-color {counts: dict[Effect,int], total, last_step} — majority vote with Dirichlet
  posterior confidence and _PRIORITY tie-break (GOAL/HARM=7, COLLECT=5, PUSH=4, TOGGLE=3, BLOCK=2, PASS=1).
- Verdict: {effect, confidence in [0,1], support n, .reliable property}.
- AffordanceModel.stats: dict[int color -> ColorStat] (primary, generalizes across instances).
- AffordanceModel.by_obj: dict[obj_key -> ColorStat] (optional per-instance override when obj_key
  provided and confident; default consumers pass color only) — P2's two-level keying for generality.
- AffordanceModel.harm: set[int], .goal: set[int] — fast O(1) sets for per-nav-step lookup by C4/C6.
- _PRIORITY: dict[Effect,int] for deterministic tie-break.
- New persisted policy fields: self.aff (AffordanceModel), self._prev_grid (np.ndarray|None),
  self._t (int step counter), self.enable_affordance (bool).
Reused as-is: movement.infer_all_translations (color->(dr,dc)), MotionModel.avatar_cells/avatar_centroid/
deltas/avatar_colors, perception.connected_components/detect_background, policy.distractor_colors set.

Proposal 1 — correctness 8/10, generality 8/10, no-regression 5/10, feasibility 9/10.
  + Clean accumulator, sensible priority tie-break (HARM/BLOCK win ties = safe), per-level reset of afm, Laplace confidence.
  + Ships dark (flag default False) which is honest about the gate.

Proposal 2 — correctness 9/10, generality 9/10, no-regression 6/10, feasibility 8/10.

Proposal 3 — correctness 8/10, generality 7/10, no-regression 10/10, feasibility 9/10.

  + Golden action-trace equality test (capture action token stream with C3 on vs off, assert identical on push+maze) converts no-regression from hope into a unit assertion. This is the single best no-regression idea across all three.
  + try/except around observe_step => C3 bug degrades to "no learning", never a policy crash.
  + Correctly keeps reset_level as a no-op (keeps cross-level priors as votes) with a one-line decay fallback documented.
  - Single-level color keying only (no per-obj override) — slightly less general than P2.
  - No click-action path — misses click/mixed games.
  - PASS conf gate via Verdict.reliable (n>=2 & conf>=0.66) is fine.

=== CORE ALGORITHM (observe_step, called once per real step, observe-only) ===

observe_step(before, after, action, mm, bg, reward, terminal, step):
  if not enable_affordance: return {}
  # --- click path (generality for click/mixed games) ---
  if action[0] == "C":
      col = component_color_at(before, x=action[1], y=action[2], bg)   # color under click
      if col is None or col == bg: return {}
      e = (HARM if terminal else GOAL if reward>0
           else COLLECT if count(after==col) < count(before==col)
           else TOGGLE if _remote_or_inplace_change(before,after,bg,{col}) else NONE)
      _record(col, e, step); return {col: e}
  # --- arrow / simple-move path ---
  if mm is None or not mm.ok or action[0] != "S": return {}
  delta = mm.deltas.get(action[1])
  if delta is None or delta == (0,0): return {}
  dr, dc = delta
  a_before = mm.avatar_cells(before)                 # np.argwhere over avatar_colors
  if len(a_before) == 0: return {}
  moved = set(map(tuple, (a_before + (dr,dc)).tolist())) == set(map(tuple, mm.avatar_cells(after).tolist()))
  # contact = cells the avatar TRIED to step into (footprint+delta, in-bounds, minus own footprint)
  target_cells = clip_inbounds(a_before + (dr,dc), before.shape) - set(a_before)
  touched = { int(before[r,c]) for (r,c) in target_cells
              if before[r,c] != bg and before[r,c] not in mm.avatar_colors
              and before[r,c] not in distractor_colors }   # distractor_colors passed in from policy
  if not touched: return {}                          # walked onto open floor -> no signal
  trans = MV.infer_all_translations(before, after, bg)    # reuse verbatim for PUSH
  results = {}
  for col in touched:
      if terminal:            e = HARM
      elif reward > 0:        e = GOAL
      elif not moved:         e = BLOCK              # avatar didn't translate -> solid
      else:
          cb, ca = count(before==col), count(after==col)
          if ca < cb and _avatar_now_on_old_col_cells(before, after, col, mm):
                              e = COLLECT
          elif trans.get(col) == (dr,dc):
                              e = PUSH               # rigid translate by SAME delta
          elif _remote_change(before, after, bg, mm.avatar_colors, exclude={col}, footprint=a_before, delta=(dr,dc)):
                              e = TOGGLE
          else:               e = PASS               # entered, col unchanged -> passable
      results[col] = e
      _record(col, e, step)                          # updates color ColorStat (+ obj_key stat if provided)
  return results

_record(col, e, step):
  if e == NONE: return
  cs = self.stats.setdefault(col, ColorStat(col)); cs.observe(e, step)
  if e == HARM: self.harm.add(col)
  if e == GOAL: self.goal.add(col)

=== CONFIDENCE (Dirichlet, from P2) ===
ColorStat.verdict():
  if not counts: return (NONE, 0.0, 0)
  winner = argmax over counts, ties broken by _PRIORITY
  alpha = 0.5  # Jeffreys
  conf = (counts[winner] + alpha) / (total + 8*alpha)
  # single-shot high-confidence override for irreversible terminal signals:
  if winner in (HARM, GOAL) and counts[winner] >= 1: conf = max(conf, 0.9)
  return (winner, conf, total)

_PRIORITY (FIXED — terminal signals dominate, BLOCK does NOT beat GOAL):
  GOAL=7, HARM=7, COLLECT=5, PUSH=4, TOGGLE=3, BLOCK=2, PASS=1, NONE=0
  (rationale: on a tie, reward/death win; among physics, COLLECT/PUSH beat BLOCK/PASS to avoid
   mislabeling an interactive object as a wall; HARM/GOAL get single-shot conf boost anyway.)

Verdict.reliable := support >= 2 and confidence >= 0.66  (HARM/GOAL reliable at support>=1 via conf boost)

=== reset_level (from P3 + P2 hybrid) ===
Default: keep the per-COLOR stats (cross-level priors as votes; contradictions outvoted over time);
clear per-OBJ stats. One-line tunable to decay counts x0.5 instead if a real game shows harmful carry.

COMPLEXITY: O(#distinct touched colors) + one infer_all_translations pass (already used in probe path).
Negligible vs 700 act/s budget; pure numpy, CPU-only, no GPU needed.

from enum import Enum
class Effect(str, Enum):
    BLOCK="BLOCK"; PASS="PASS"; PUSH="PUSH"; COLLECT="COLLECT"
    TOGGLE="TOGGLE"; GOAL="GOAL"; HARM="HARM"; NONE="NONE"

@dataclass
class Verdict:
    effect: Effect
    confidence: float        # 0..1
    support: int             # n contacts
    @property
    def reliable(self) -> bool: ...   # support>=2 and conf>=0.66 (HARM/GOAL: support>=1)

@dataclass
class ColorStat:
    color: int
    counts: dict[Effect,int]
    total: int
    last_step: int
    def observe(self, e: Effect, step: int) -> None: ...
    def verdict(self) -> tuple[Effect, float, int]: ...

class AffordanceModel:
    def __init__(self) -> None: ...
    # learning (observe-only; pure; never alters caller state):
    def observe_step(self, before: np.ndarray, after: np.ndarray, action: tuple,
                     mm, bg: int, reward: float, terminal: bool, step: int = 0,
                     distractor_colors: frozenset[int] = frozenset(),
                     obj_key: tuple | None = None) -> dict[int, Effect]: ...
    # query API (the C4/C6 contract):
    def affordance(self, color: int, obj_key: tuple | None = None) -> Verdict: ...
    def blocks(self, color: int) -> bool: ...           # reliable BLOCK -> wall set for C6

    def pushables(self) -> list[int]: ...               # reliable PUSH colors -> sokoban planner
    def collectibles(self) -> list[int]: ...
    def goal_colors(self) -> list[int]: ...
    def harm_colors(self) -> list[int]: ...
    def navigation_cost(self, color: int) -> float: ... # HARM/BLOCK->inf, PUSH->push_cost, GOAL/COLLECT->0, else 1 (for C6 A*)
    def reset_level(self) -> None: ...                  # keep color stats, clear obj stats

## Risks
- COLOR != OBJECT identity: two roles sharing a color get merged. Mitigated by Dirichlet confidence
  (conflicts keep conf below the reliable gate -> treated as NONE/optimistic) + optional per-obj override
  (by_obj) + one-line key swap to (color, shape_sig) when C1 lands.
- TOGGLE/COLLECT false positives without C2: _remote_change may misread the avatar's own footprint trail.
  Mitigated by subtracting avatar before/after footprint, excluding distractor_colors, low TOGGLE priority
  (outvoted), and majority vote. Flagged as the C2 replacement seam.
- Cross-level color re-skin: keeping color stats may carry a stale label. Mitigated by votes (2 fresh
  contradicting contacts outvote) and a documented one-line decay-x0.5 fallback in reset_level.
- Multi-cell / multi-color avatar contacting several objects in one step: emit one verdict per touched
  color, classify independently; avatar_colors excluded from touched; contact computed on BEFORE grid
  pre-overlap.
- HARM mislearned from an unrelated same-step death: accepted as conservative over-avoidance; but since
  C3 is observe-only this PR, it cannot cause avoidance now — risk is deferred to C6 which gates on
  is_harm only for the contacted color and can still route via graph fallback.
- BIGGEST PROJECT RISK — scope creep into the decision path (the historical push-regression cause):
  hard-gated out. observe-only + golden action-trace test + try/except make it structurally impossible
  for C3 to change actions in this PR.
- Click games: handled by the click path so C3 is not inert on click/mixed (generality), but those
  verdicts are lower-leverage until C5/C6 consume them.
