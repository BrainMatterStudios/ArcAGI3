# C1 — Object tracking / persistence

**Confidence:** 0.88

## Summary
Ship C1 as a new, dormant `src/arcagi3/tracking.py` module: an `ObjectTracker` that consumes the already-memoized `perception.connected_components` output (it never re-segments and never re-implements geometry), assigns stable per-instance integer ids across frames, and emits a typed event stream {APPEARED, VANISHED, MOVED, CHANGED} (with RECOLORED and SPLIT/MERGE as first-class but conservatively-gated sub-cases). Matching is per-color, motion-aware greedy nearest-neighbour with a distance gate and a translation/velocity prior reusing `movement.infer_all_translations`, plus a short occlusion grace with velocity coasting to stop avatar-over-floor flicker. The decisive design choice — taken from all three proposals — is that C1 changes ZERO actions on the no-regression suite: it lands with no call site in the live path (strongest guarantee), and the optional, separately-committed wiring is behind a default-OFF `track_objects` flag whose output is never read by `_choose`, proven neutral by a byte-identical action-trace A/B across the 8 local games + push 3/3. This protects the fragile sokoban/push graph path that has repeatedly regressed.

## Data structures
TrackedObj (extends perception.Obj's fields with temporal state: id, age, missed, first_seen, last_seen, velocity:(float,float) EMA of centroid delta, color_history:tuple[int]). Event{kind,id,color,delta,size_delta,before:(bbox,size),after:(bbox,size),extra:dict for split/merge lineage}. TrackResult{objects, events, correspondences:dict[cur_idx->prev_id], by_id:dict[id->TrackedObj]}. cells kept as tuple[(r,c)] (from Obj) and converted to frozenset on demand for O(min) overlap/IoU in split/merge — cheap given small object cell-counts on 64x64. Tracker holds _tracks:dict[id->TrackedObj], monotonic _next_id, _frame, prev_grid for translation prior.

## Algorithm
DATA STRUCTURES (tracking.py):
- TrackedObj{id:int, color, cells:tuple[(r,c)], bbox, size, centroid, age=0, missed=0, first_seen=0, last_seen=0, velocity=(0.0,0.0), color_history=()}
- Event{kind:str, id:int, color:int, delta=(0.0,0.0), size_delta=None, before=(bbox,size)|None, after=(bbox,size)|None, extra:dict}  # extra holds split into=[ids]/merge from=[ids]
- TrackResult{objects:list[TrackedObj], events:list[Event], correspondences:dict[int(cur_idx)->int(prev_id)], by_id:dict[int->TrackedObj]}
- Constants: APPEARED, VANISHED, MOVED, CHANGED, RECOLORED, SPLIT, MERGED.

ObjectTracker state: bg, ignore_colors, _next_id(monotonic, NOT reset on level), _tracks:dict[id->TrackedObj], _frame.
Tunables (conservative, hand-set, documented): max_match_dist=8.0, occlusion_grace=2, overlap_thresh=0.5, velocity_ema=0.5, w_size=0.25 (tie-break only).

objects(grid) -> list[TrackedObj] (stateless, ids=-1):
  bg = self.bg or P.detect_background(grid)
  return [TrackedObj.from_obj(-1,o,self._frame) for o in P.connected_components(grid, background=bg) if o.color not in self.ignore_colors]

match(prev:list[TrackedObj], cur:list[Obj], translations=None) -> TrackResult  (PURE: no mutation of inputs, no I/O):
  0. group prev and cur by color. (Identity only assigned within a color; cross-color change handled as RECOLORED only via the in-place overlap test in step 2b, else VANISHED+APPEARED — conservative.)
  1. predict prev centroid: if translations has color k -> pred=centroid+(dr,dc); else pred=centroid+velocity (constant-velocity; 0 for statics).
  2a. SPLIT/MERGE PASS (before 1-1), per color, using exact cell-set overlap (frozenset intersection on cells):
        MERGE: if >=2 prev objs each overlap the SAME cur obj by >= overlap_thresh of THEIR OWN cells -> cur inherits OLDEST prev id; emit MERGED{into:id, from:[other ids]}; remove them from pool.
        SPLIT: if one prev obj overlaps >=2 cur objs each by >= overlap_thresh of THAT CUR obj's cells -> largest fragment keeps prev id, others new ids; emit SPLIT{id, into:[ids]}; remove from pool.
        (Guard: skip split/merge if avatar/ignore colors involved; thresholds strict to avoid avatar-overlap false positives.)
  2b. RECOLORED (optional, cheap): a prev obj and a cur obj of DIFFERENT color whose cell-sets are identical (same footprint) -> same id, emit RECOLORED{old,new}. Used for switch->door. Default ON but only fires on exact-footprint match so it cannot mis-merge.
  3. 1-1 cost matrix per color over remaining pairs: cost = manhattan(pred, cur.centroid) + w_size*(prev.size!=cur.size); DISCARD pairs with raw centroid dist > max_match_dist.
  4. GREEDY assignment: collect (cost, prev_id, cur_idx) triples, sort by (cost, prev_id, cur_idx) [deterministic tie-break], assign in order skipping taken prev_id/cur_idx.
  5. EMIT per matched pair: ddr,ddc = cur.centroid - prev.centroid.
        rigid = _is_rigid_shift(prev.cells, cur.cells, round(ddr), round(ddc))  # inlined from movement.py:91-92
        if round(ddr)!=0 or round(ddc)!=0: emit MOVED{delta,(before),(after)}
        if not rigid or cur.size!=prev.size: emit CHANGED{size_delta,before,after}  # MOVED and CHANGED are independent flags
        carry id; bump age; missed=0; velocity = ema(prev.velocity, (ddr,ddc)); update color_history.
     unmatched cur -> APPEARED, allocate id=_next_id++ (id assigned in step()/update, not match-pure-call; in pure match emit with id=-1 placeholder).
     unmatched prev -> missed+=1; if missed > occlusion_grace -> VANISHED{before}; else keep alive, coast centroid by velocity (no event yet).
  return TrackResult(...)

update(grid, background=None, ignore_colors=None) -> TrackResult (STATEFUL convenience for C2/C7):
  refresh bg/ignore; cur = objects(grid); translations = MV.infer_all_translations(prev_grid, grid, bg) if prev_grid else None;
  res = match(live prev tracks, cur, translations); rebuild self._tracks applying correspondences + allocating ids for APPEARED + dropping VANISHED; _frame++; cache last; return res.
reset(): clear _tracks, _frame=0; KEEP _next_id monotonic (ids never ambiguous across levels).
_is_rigid_shift(prev_cells, cur_cells, dr, dc): set(shift prev by dr,dc) == set(cur)  # inline, no edit to movement.py.

## No-regression strategy
Three layered guarantees, strongest first:
1. DORMANT LANDING (the C1 PR): tracking.py + tests/test_tracking.py ONLY. No import of `tracking` anywhere in policy.py/agent.py. With no call site, every executed code path is byte-identical -> local suite 8/8 (27/27) + push 3/3 + pytest provably unchanged. This is the strongest possible no-regression posture and is sufficient to ship C1 (it unblocks C2 against the unit-tested API).
2. GATED WIRING (separate commit, optional): add track_objects flag (default False) + the single gated update() call + reset hooks. Because update()'s output is never read by _choose/_nav_step/_next_target, chosen actions are identical even with the flag ON. PROVE it with an ACTION-TRACE-EQUALITY test: run all 8 local games with flag off vs on and assert byte-identical action sequences (policy is deterministic, seeded). This is a concrete proof, not just "tests pass".
3. ISOLATION INVARIANTS: (a) objects() calls the EXISTING memoized connected_components read-only (no cache invalidation -> click salience / state hashing / nav targeting bit-identical); (b) tracker ignores exactly distractor_colors -> never feeds a counter downstream, consistent with the ls20 fix; (c) rigid-shift test is INLINED, movement.py NOT refactored, so test_movement.py cannot regress; (d) _changed_colors left untouched; (e) no edit to agent.py / object_state_key / WorldModel -> the fragile push graph path is structurally untouched. Determinism: no RNG, greedy sorts by (cost,prev_id,cur_idx). Throughput guard: micro-benchmark test on a ~40-object 64x64 frame; require <3% actions/sec loss on ls20. Revert is trivial: delete tracking.py + the flag + the gated lines.

## Risks
R1 Same-color adjacent objects merge into one component (avatar steps onto same-color item): handled as MERGE event (lineage preserved) rather than silent id loss; document ids as best-effort, EVENTS as authoritative for downstream. R2 Avatar-over-floor flicker (the exact class that caused prior regressions): occlusion_grace + velocity coasting + per-color shape-aware matching prevent spurious VANISHED/APPEARED. R3 Split/merge false positives from avatar overlapping two items: strict own-cells overlap_thresh=0.5 and skipping avatar/ignore colors; can disable via detect_split_merge=False. R4 Cost/threshold overfit to 8 local archetypes: weights hand-set, conservative, documented, NOT tuned on the local suite; generality validated on the held-out real set in W2, and since C1 output is unconsumed it cannot regress regardless. R5 Symmetric teleport of two identical same-color objects in one step is unresolvable from a single frame pair (greedy picks nearest) — flagged as known limitation for C5. R6 match() is pure but update() is stateful (spec implies purity): documented; update() is the only side-effecting entry; never advance one tracker from two consumers. R7 Subframe animation: tracker operates on settled grid via to_grid like the rest of the codebase; intra-step animation never reaches it (C2's concern).
